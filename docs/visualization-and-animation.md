# Visualization and Animation

ODEM supports three visualization levels.

## Static Plotting

The static plot dispatcher renders detailed PDFs from a run bundle:

```bash
python main.py plot results/RUN_ID --static
```

It reads saved raw arrays and writes into `plots/`. Dashboards, sweep figures,
and animations use `odem.visualization`. Shared style, data preparation, and
visual artifact checks live in `odem.plot_style`, `odem.plot_data`, and
`odem.visual_checks`.
When static plotting is requested, bundle validation requires the core PDF set
to be present and checksum-recorded.

## Diagnostic Dashboard

The diagnostic dashboard renders a multi-panel PNG containing:

- VFE over time,
- cumulative free action,
- accuracy and complexity traces,
- multi-dimension state tracking,
- residual norm,
- parameter and precision traces,
- posterior covariance trace,
- manifest and validation snapshot.

```bash
python main.py plot results/RUN_ID --dashboard
```

## State Animation

Animations compare true/noisy state trajectories with inferred state
trajectories:

```bash
python main.py plot results/RUN_ID --animations
```

The default output is `animations/state_estimation.gif`. The animation helper
uses the saved `x_noisy.npy` and `gen_x_estimates.npy` arrays, so it can be run
after the numerical experiment completes. Frames include trajectory trails,
current markers, and per-frame error text. Dashboard and animation state-array
validation is shared with `odem.analysis` through `odem.arrays`.

## Artifact Galleries

`python main.py report ...` writes `index.html` alongside report files. The
gallery is static HTML generated by `odem.reporting`; it embeds PNG/GIF assets
and links PDF, JSON, CSV, Markdown, and HTML report outputs without additional
runtime dependencies.
